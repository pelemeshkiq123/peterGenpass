# Генератор паролей Николая Пахомова

## 🔐 О проекте

Этот проект представляет собой улучшенную версию классического генератора паролей PeterGenpass. Изначальный код был взят за основу и значительно доработан для создания мощного и удобного инструмента генерации паролей с особым вниманием к безопасности и юзабилити.

Проект выполнен в качестве пет-проекта (pet project) для изучения возможностей JavaScript, работы с DOM, генерации случайных данных и создания пользовательских интерфейсов.

## 🚀 Особенности

### Основные возможности:
- **Два режима генерации:**
  - *Полностью случайный пароль* — максимальная энтропия, идеально для критически важных систем
  - *Произносимый пароль (pwgen)* — легко запоминающиеся, но достаточно надежные пароли

### Расширенные настройки:
- Выбор наборов символов (a-z, A-Z, 0-9, специальные символы)
- Исключение неоднозначных символов (B8G6I1l|0OQDS5Z2) для удобства чтения и ввода
- Настройка длины пароля и количества генерируемых паролей
- Отображение энтропии (бит) для оценки надежности

### 💀 Специальный режим "Николай Пахомов":
- Генерирует 5 паролей длиной 20 символов
- Использует все доступные наборы символов
- Максимальная степень случайности
- Зловещий дизайн кнопки с пульсирующим красным свечением

## 🛠️ Технологии

- HTML5
- CSS3 (с кастомными анимациями)
- JavaScript (ES6)
- jQuery (для удобства работы с DOM)
